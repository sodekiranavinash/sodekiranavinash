### 🏆 get1agent — AI Agent &amp; Workflow Builder
**A fully serverless, multi-tenant platform for building, running and sharing AI capabilities — knowledge bases, tools, skills, agents and multi-agent workflows on managed AWS.**

[![Live](https://img.shields.io/badge/live-get1agent.com-22D3EE?style=for-the-badge&logo=googlechrome&logoColor=white)](https://get1agent.com)
[![GitHub](https://img.shields.io/badge/source-get1agent-181717?style=for-the-badge&logo=github&logoColor=white)](https://github.com/sodekiranavinash/get1agent)
[![License](https://img.shields.io/badge/license-Apache%202.0-blue?style=for-the-badge)](https://github.com/sodekiranavinash/get1agent/blob/main/LICENSE)

</div>

- **Serverless by design** — no servers, no clusters, no VPC, no relational DB. **DynamoDB** holds metadata, **S3** holds artifacts, **S3 Vectors** holds the semantic index, and **Bedrock AgentCore** runs agent workers across **10+ AWS services**.
- **Multi-agent runtime** on Bedrock AgentCore + **Strands** with **Graph** (deterministic) and **Swarm** (dynamic handoff) topologies, per-node overrides, MCP &amp; custom tools, planner-driven execution, live streaming runs, human-in-the-loop, AgentCore Policy and user-scoped long-term memory.
- **Production-grade retrieval** — hybrid **semantic + BM25** fused with **RRF**, opt-in reranking, and parent-child (small-to-big) retrieval serving grounded, cited answers.
- **Closes the quality loop** with a **Ragas-aligned evaluation lab**: golden datasets from live traces, annotation queues, deterministic retrieval &amp; trajectory scoring, LLM-as-a-judge with structured outputs, side-by-side trace replay and A/B testing across models.
- **Extensible** — AI-assisted workspace to generate &amp; sandbox-test custom MCP servers, OAuth 2.0 connections to remote MCP servers, and importable Strands-format skills.

`Python` `React 19` `AWS Lambda` `Bedrock AgentCore` `Strands` `S3 Vectors` `DynamoDB` `MCP` `Code Interpreter` `Terraform` `GitHub Actions`
